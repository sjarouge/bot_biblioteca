# 🚀 Inicio Rápido - BOT Biblioteca W2M

## ⚡ Inicio en 3 Pasos

### 1️⃣ Probar Localmente (Opcional)

```bash
cd bot_biblioteca
pip install -r requirements.txt
streamlit run app.py
```

Abre tu navegador en `http://localhost:8501`

### 2️⃣ Desplegar en Streamlit Cloud (Recomendado)

1. **Sube a GitHub:**
   ```bash
   git init
   git add .
   git commit -m "BOT Biblioteca W2M"
   git remote add origin [TU_REPO]
   git push -u origin main
   ```

2. **Despliega:**
   - Ve a [share.streamlit.io](https://share.streamlit.io)
   - Conecta tu repositorio
   - Configura: `Main file path: bot_biblioteca/app.py`
   - Click "Deploy"

3. **Comparte:**
   - Copia la URL generada
   - Compártela con tu compañero
   - **¡Listo!** No necesita instalar nada

### 3️⃣ Usar el BOT

1. Abre la aplicación (local o en la nube)
2. En la barra lateral, ingresa la ruta de tu biblioteca
3. Click en "🔄 Indexar Biblioteca"
4. Haz preguntas en el chat

## 💡 Ejemplos de Preguntas

- "¿Qué programas hay para facturas?"
- "¿Cómo funciona ZFI_BLUEBAY_GET?"
- "¿Qué reports de finanzas existen?"
- "¿Dónde están los programas de Azure?"
- "¿Qué programas hay para República Dominicana?"
