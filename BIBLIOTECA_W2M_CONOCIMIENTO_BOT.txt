PROYECTO ESPECIAL: ZFI_DOM - REPUBLICA DOMINICANA
=================================================
Proyecto de facturacion electronica para Republica Dominicana
Ubicacion: PAQUETES_SAP/ZFI_W2M/ZFI_ECOMMERCE/ZFI_DOM_DOMINICANA/

PROGRAMAS DEL PROYECTO DOMINICANA:
1. ZFIR00426 - Facturacion PUJ Limite 250k DOP
   - Tipo: Report Principal de Facturacion
   - Funcion: Procesamiento de facturas PUJ con limite fiscal de 250,000 DOP
   - Complejidad: Media (4 dictionary objects)
   - Criticidad: Alta

2. ZFIR00427 - Facturacion PUJ Reporting
   - Tipo: Report de Analisis y Estadisticas
   - Funcion: Analisis y reporting complementario de facturacion PUJ
   - Complejidad: Baja (1 dictionary object)
   - Criticidad: Media

3. ZFIR00442 - Facturacion Agrupada
   - Tipo: Report de Procesamiento Avanzado
   - Funcion: Optimizacion fiscal mediante agrupacion inteligente de facturas
   - Complejidad: Alta (8 dictionary objects)
   - Criticidad: Alta

4. ZFIR00443 - Facturacion Agrupada Reporting
   - Tipo: Report de Analisis Agrupado
   - Funcion: Analisis y reporting de facturacion agrupada
   - Complejidad: Baja (1 dictionary object)
   - Criticidad: Media

5. ZFIR00445 - Generacion XML Dominicana *** CRITICO ***
   - Tipo: Generador de XML Fiscal
   - Funcion: Genera ficheros XML para cumplimiento normativo DGII
   - Complejidad: Muy Alta (3 function modules + 1 screen)
   - Criticidad: CRITICA
   - Integracion: FactureHoy (plataforma dominicana)
   - Control: Fecha limite 3 de cada mes
   - Function Modules:
     * z_grabar_fichero_serv - Grabacion en servidor
     * z_obtener_rutas_int_salida - Rutas productivas
     * z_obtener_rutas_int_test - Rutas de prueba

6. ZFIR00446 - Apertura Periodos Dominicana
   - Tipo: Transaccion de Gestion Fiscal
   - Funcion: Gestion y apertura de periodos fiscales dominicanos
   - Complejidad: Media (2 dictionary objects + 1 screen)
   - Criticidad: Alta

7. ZFIR00447 - Procesamiento Especializado
   - Tipo: Report de Procesamiento
   - Funcion: Procesamiento especializado (requiere analisis detallado)
   - Complejidad: Media (2 dictionary objects + 1 function module)
   - Criticidad: Media

8. ZFIR00448 - Monitor Ficheros XML
   - Tipo: Monitor de Archivos XML
   - Funcion: Monitoreo y auditoria de ficheros XML generados
   - Complejidad: Alta (4 dictionary objects + 2 screens)
   - Criticidad: Alta

9. ZFIR00449 - Report Complementario
   - Tipo: Report Simple
   - Funcion: Report complementario (requiere analisis)
   - Complejidad: Baja (1 dictionary object)
   - Criticidad: Baja

10. ZFIR00451 - Procesamiento de Conversion
    - Tipo: Report de Procesamiento
    - Funcion: Conversion de formatos VX a DOM
    - Complejidad: Media (2 dictionary objects)
    - Criticidad: Media

11. ZFIR00452 - Report Basico
