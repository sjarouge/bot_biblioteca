FUNCIONES BAPI Y FUNCTION MODULES PARA CONTABILIZAR FACTURAS
=============================================================

BAPI_ACC_DOCUMENT_POST (BAPI Principal de Contabilizacion)
------------------------------------------------------------
- Tipo: BAPI estandar SAP
- Uso: Contabiliza documentos contables (facturas, pagos, etc.)
- Programas que la usan:
  * ZFIR00426 - Facturacion PUJ Limite 250k DOP
  * ZFIR00442 - Facturacion Agrupada
- Parametros de entrada (EXPORTING):
  * documentheader - Cabecera del documento (sociedad, fecha, tipo documento, moneda, etc.)
- Parametros de entrada (TABLES):
  * accountreceivable - Cuentas a cobrar (proveedores, clientes)
  * accountgl - Cuentas de mayor (GL accounts)
  * currencyamount - Importes en diferentes monedas
  * accounttax - Impuestos
  * extension2 - Extensiones personalizadas (posting keys, etc.)
- Parametros de salida (TABLES):
  * return - Mensajes de retorno (exito, errores, warnings)
- Retorna en return:
  * Si exito: type='S', id='RW', number='605', message_v2 contiene numero documento y ejercicio
  * Numero documento: ls_return-message_v2(10) - primeros 10 caracteres
  * Ejercicio: ls_return-message_v2+14(4) - desde posicion 14, 4 caracteres
- Tablas afectadas: BKPF (cabecera), BSEG (posiciones)
- Cuando usar: Para contabilizar facturas nuevas
- Ejemplo de uso en ZFIR00426:
  CALL FUNCTION 'BAPI_ACC_DOCUMENT_POST'
    EXPORTING
      documentheader    = ls_header
    TABLES
      accountreceivable = lt_accountreceivable
      accountgl         = lt_glaccount
      currencyamount    = lt_currencyamount
      accounttax        = lt_accounttax
      extension2        = lt_bapiparex
      return            = lt_return

BAPI_ACC_DOCUMENT_CHECK (Validacion antes de Contabilizar)
-----------------------------------------------------------
- Tipo: BAPI estandar SAP
- Uso: Valida documento antes de contabilizar (simulacion)
- Programas que la usan:
  * ZFIR00426 - Facturacion PUJ (validacion previa)
  * ZFIR00442 - Facturacion Agrupada (validacion previa)
- Parametros: Iguales que BAPI_ACC_DOCUMENT_POST
- Diferencia: No contabiliza, solo valida
- Cuando usar: Para validar datos antes de contabilizar realmente
- Retorna: Mensajes de validacion sin crear documento
- Ejemplo de uso:
  CALL FUNCTION 'BAPI_ACC_DOCUMENT_CHECK'
    EXPORTING
      documentheader    = ls_header
    TABLES
      accountreceivable = lt_accountreceivable
      accountgl         = lt_glaccount
      currencyamount    = lt_currencyamount
      accounttax        = lt_accounttax
      extension2        = lt_bapiparex
      return            = lt_return

BAPI_TRANSACTION_COMMIT (Confirmar Transaccion)
------------------------------------------------
- Tipo: BAPI estandar SAP
- Uso: Confirma transaccion despues de BAPI_ACC_DOCUMENT_POST
- Programas que la usan:
  * ZFIR00426 - Confirma contabilizacion
  * ZFIR00442 - Confirma contabilizacion
- Cuando usar: Despues de BAPI_ACC_DOCUMENT_POST exitoso
- Importante: Sin COMMIT, los cambios no se guardan permanentemente
- Ejemplo de uso:
  CALL FUNCTION 'BAPI_TRANSACTION_COMMIT'
    EXPORTING
      wait = abap_true

BAPI_TRANSACTION_ROLLBACK (Revertir Transaccion)
-------------------------------------------------
- Tipo: BAPI estandar SAP
- Uso: Revierte transaccion si hay errores
- Programas que la usan:
  * ZFIR00426 - Revierte si hay error en contabilizacion
  * ZFIR00442 - Revierte si hay error en contabilizacion
- Cuando usar: Si BAPI_ACC_DOCUMENT_POST retorna errores
- Importante: Deshace todos los cambios de la transaccion
- Ejemplo de uso:
  CALL FUNCTION 'BAPI_TRANSACTION_ROLLBACK'

Z_UPDATE_DOCUMENT (Modificacion de Documentos Contables)
---------------------------------------------------------
- Tipo: Function Module personalizado
- Uso: Modifica documentos contables ya contabilizados
- Ubicacion: zfi_mod_fact/z_update_document/z_update_document.txt
- Programas que la usan:
  * ZFI_MOD_FACT - Modificacion de facturas (uso principal)
  * ZARR00172 - Actualizacion de campo XREF1_HD (uso indirecto)
- Parametros de entrada (IMPORTING):
  * i_belnr - Numero de documento contable (BELNR_D)
  * i_bukrs - Codigo de sociedad (BUKRS)
  * i_gjahr - Ejercicio fiscal (GJAHR)
  * it_bkpf - Tabla de campos BKPF a modificar (ZFI_TABLA_CAMPO_VALOR)
  * it_bseg - Tabla de campos BSEG a modificar (ZFI_TABLA_BSEG_CAMPO_VALOR)
- Tablas modificadas: BKPF (cabecera documentos), BSEG (posiciones documentos)
- Metodo: Usa CHANGE_DOCUMENT estandar SAP
- Auditoria: Implementa zcl_log_contable=>add_document_log
- Riesgo: ALTO - Modifica tablas contables estandar
- Cuando usar: Para corregir errores en facturas ya contabilizadas
- Estructura it_bkpf/it_bseg:
  * campo - Nombre del campo a modificar (ej: 'XREF1_HD', 'BKTXT')
  * valor - Nuevo valor para el campo
- Ejemplo de uso en ZFI_MOD_FACT:
  CALL FUNCTION 'Z_UPDATE_DOCUMENT'
    EXPORTING
      i_belnr = pa_belnr
      i_bukrs = pa_bukrs
      i_gjahr = pa_gjahr
      it_bkpf = pt_campos_bkpf
      it_bseg = pt_campos_bseg
- Ejemplo de uso en ZARR00172:
  wa_campos_bkpf-campo = 'XREF1_HD'.
  CONCATENATE sy-datum sy-uzeit anulado
         INTO wa_campos_bkpf-valor
         SEPARATED BY space.
  CALL FUNCTION 'Z_UPDATE_DOCUMENT'
    EXPORTING
      i_belnr = pw_bsid-belnr
      i_bukrs = pw_bsid-bukrs
      i_gjahr = pw_bsid-gjahr
      it_bkpf = it_campos_bkpf
      it_bseg = it_campos_bseg

FLUJO COMPLETO DE CONTABILIZACION CON BAPIs
============================================

Paso 1: Preparar datos
- Crear documentheader con sociedad, fecha, tipo documento
- Llenar accountreceivable con datos de proveedores/clientes
- Llenar accountgl con cuentas de mayor
- Llenar currencyamount con importes
- Llenar accounttax con impuestos
- Llenar extension2 con posting keys y extensiones

Paso 2: Validar (Opcional pero recomendado)
- CALL FUNCTION 'BAPI_ACC_DOCUMENT_CHECK'
- Verificar return para errores
- Si hay errores, corregir datos y repetir validacion

Paso 3: Contabilizar
- CALL FUNCTION 'BAPI_ACC_DOCUMENT_POST'
- Verificar return:
  * Buscar type='S', id='RW', number='605' para exito
  * Extraer numero documento de message_v2(10)
  * Extraer ejercicio de message_v2+14(4)

Paso 4: Confirmar o Revertir
- Si exito: CALL FUNCTION 'BAPI_TRANSACTION_COMMIT'
- Si error: CALL FUNCTION 'BAPI_TRANSACTION_ROLLBACK'

CASOS DE USO DETALLADOS
========================

CASO 1: CONTABILIZAR FACTURAS PUJ DOMINICANAS
Pregunta: "¿Como contabilizo facturas PUJ de Republica Dominicana?"
Respuesta: 
1. Usa ZFIR00426 - Facturacion PUJ Limite 250k DOP
2. Introduce fecha contable y sociedad
3. El programa valida que las facturas no superen 250,000 DOP
4. Agrupa facturas si es necesario
5. Contabiliza usando BAPI_ACC_DOCUMENT_POST
6. Verifica resultados en ZFIR00427

CASO 2: MODIFICAR FACTURA YA CONTABILIZADA
Pregunta: "¿Como corrijo un error en una factura ya contabilizada?"
Respuesta:
1. Usa ZFI_MOD_FACT - Modificacion de Facturas
2. Introduce: numero documento (pa_belnr), sociedad (pa_bukrs), ejercicio (pa_gjahr)
3. Especifica campo a modificar (pa_bkcam para BKPF o pa_bgcam para BSEG)
4. Introduce nuevo valor (pa_bkval o pa_bgval)
5. Ejecuta - El programa usa Z_UPDATE_DOCUMENT para modificar
6. Se registra en auditoria automaticamente
7. IMPORTANTE: Solo usuarios autorizados, riesgo alto

CASO 3: GENERAR XML FISCAL DOMINICANO
Pregunta: "¿Como genero los XMLs fiscales para Republica Dominicana?"
Respuesta:
1. Usa ZFIR00445 - Generacion XML Dominicana (CRITICO)
2. Ejecutar ANTES del dia 3 de cada mes
3. El programa genera XMLs para cumplimiento DGII
4. Usa z_grabar_fichero_serv para guardar en servidor
5. Usa z_obtener_rutas_int_salida para rutas productivas
6. Verifica con ZFIR00448 - Monitor Ficheros XML
7. Si no se ejecuta a tiempo: sanciones fiscales

CASO 4: PROCESAR PAGOS XML
Pregunta: "¿Como proceso pagos recibidos en XML?"
Respuesta:
1. Usa ZFI_PAYMENTS_XML - Procesamiento de Pagos XML
2. El programa lee archivos XML de pagos
3. Valida y procesa los pagos
4. Contabiliza automaticamente
5. Genera logs de procesamiento

CASO 5: OPTIMIZAR FACTURACION FISCAL
Pregunta: "¿Como optimizo la facturacion para cumplimiento fiscal?"
Respuesta:
1. Usa ZFIR00442 - Facturacion Agrupada
2. El programa agrupa facturas relacionadas
3. Contabiliza de forma optimizada
4. Verifica resultados con ZFIR00443
5. Reduce numero de documentos contables

CASO 6: PREPARAR DOCUMENTOS PARA CONTABILIZAR
Pregunta: "¿Como preparo documentos antes de contabilizar?"
Respuesta:
1. Usa ZFI_ENVIABLE - Gestion de Documentos Enviables
2. Marca documentos como enviables
3. Usa ZFI_ENVIABLE_UPD para actualizar estados
4. Luego ejecuta programa de contabilizacion (ZFIR00426, etc.)
